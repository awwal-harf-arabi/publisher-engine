# أول حرف عربي — Publishing Engine

A reusable book-publishing command-line engine for independent, Arabic-first fiction repositories. **No manuscript content is stored here.** Each novel or series lives in its own private repository and can have multiple volumes and 120+ locale editions.

## Installation

Python 3.11+, Pandoc 3.x, system fonts (`Amiri`, `Noto Serif`, with locale-specific fallbacks), WeasyPrint and Pillow:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
python -m unittest discover -s tests -v
```

## Commands

```bash
awwal-publish validate --repo ../novel-template --book 01 --lang ar --mode preview
awwal-publish build --repo ../novel-template --book 01 --lang ar --mode preview --formats epub,digital-pdf,print-pdf,docx,html
awwal-publish spine --pages 350 --sheet-thickness-mm 0.092 --trim-width-mm 148 --trim-height-mm 210 --bleed-mm 3
```

`--mode release` blocks if chapters aren't approved, editorial placeholders remain, the edition/rights aren't approved, the translation is stale, approved art is missing, or a named printer's signed-off paper proof is required for print.

## Output contract

| File | Use | Meaning |
|---|---|---|
| `Book.epub` | EPUB3, Kindle/Apple Books/Kobo upload candidate | Validate with EPUBCheck and Kindle Previewer; no fake `.kpf` |
| `Book-Digital.pdf` | Direct-sale PDF/reader file | NOT mobile-reflowable like EPUB |
| `Book-Print-Interior.pdf` | Mirrored, trimmed print interior | Requires vendor-specific prepress verification, not a complete cover |
| `Book.docx` | Editable edition/intermediate | Proof RTL in Word before distributing |
| `Book-Preview.html` | Browser proof | No DRM or storefront upload |
| `preflight.json`, `manifest.json`, `SHA256SUMS` | Audit and checksums | SHA256 of each generated artifact |

### Output limitations

- `KPF` requires Kindle Create/Previewer workflow and is not generated by this project.
- Paperback/hardcover cover spreads are not built without final page count, paper thickness and printer specs; `spine` only computes provisional geometry.
- PDF/X, embedded ICC profiles, press-specific bleed and color space are a **prepress stage** and are not guaranteed by the generic PDF generator.
- Any audio audiobook (`M4B`, `MP3`, ACX-style chapter files) needs a separate narration/rights/QA workflow.
- The current EPUB builder is designed for reflowable prose. Image-heavy fixed layouts, CJK vertical layout, ruby annotations and complex Indic scripts require further templates and per-language QA.
- 120+ language support means configurable locale editions, not that translated prose appears automatically.

## Architecture

Source chapters are read-only. Build stages: `source Markdown -> strict preflight -> normalized Markdown -> Pandoc EPUB3/DOCX/HTML -> WeasyPrint PDF -> artifact hashes`. Every locale/volume is built and approved independently. Studio-specific cover/ISBN/sales prices are retained per distribution channel, not globally guessed.

## Security and CI

- Pin the exact publisher engine commit SHA in `ENGINE_REF`, set `ENGINE_REPOSITORY=ORG/publisher-engine` in each novel repository's GitHub Actions variables.
- Keep manuscripts private; only the publishing engine may be public.
- Use GitHub branch protections and `publication-approval` environment reviewers before running `release.yml`.
- GitHub Actions artifacts are for internal review, not storefront delivery.
- Vendor payment credentials, retailer tokens, and upload keys must be GitHub secrets and are **not** used by this starter.

### Store policy and translation provenance

Amazon KDP currently allows Arabic eBooks, not Arabic paperback publishing. Do not claim that a print-interior proof is Amazon-ready. KDP distinguishes AI-generated text, images, and translations from merely AI-assisted work and requires disclosure of AI-generated content. See its current content guidelines before publication. GitHub private-repository environment approval availability depends on plan; strict release metadata gates run independently of GitHub review rules.

To validate or build **every available edition** of a particular volume, pass `--lang all`; missing translations will fail preflight rather than being fabricated.
